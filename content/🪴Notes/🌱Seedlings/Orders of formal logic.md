## Zeroth order logic
- Logic of propositions
- Only deals with logical objects (propositions) and logical connectors
- Example: Socrates is a man 
## First order logic
- Logic of predicates
- Introduces quantifiers over non-logical objects
- Example: $\exists$ a man, and this man is Socrates 
- Some modern logicians have argued that such objects can be [[Non-existent objects]]
